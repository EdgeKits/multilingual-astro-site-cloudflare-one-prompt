  What it is. A site for Plumbline, a made-up company name for the AI funnel

  - Pages: /<locale>/, /<locale>/about/ and /<locale>/contacts/. All copy is
    translated by hand into the four languages.
  - Design: the home page leads with a sample audit of a dental clinic. Bars
    shrink at each step (seen on Google → opened site → called → booked), and a
    yellow highlight marks where customers were lost and why. Numbers are
    formatted for each language.
  - i18n: uses @edgekits/astro-i18n, since your project settings enable it.
    Translations live in Workers KV and are type-checked. A visit to / goes to
    the right language by cookie, then browser language, then country, then
    English.
  - Your extras: flags in the language switcher, country-based language choice,
    and English Markdown copies of each page (/en-us/about.md) plus /llms.txt. I
    also added sitemap.xml (with language alternates), robots.txt, hreflang
    tags and a localized 404 page.

  - It's a React component using react-hook-form, submitted through an Astro
    Action. The action checks the input, replies, and sends nothing.
  - On success the form is replaced by "Sent successfully" in the visitor's
    language: "Enviado correctamente", "Enviado com sucesso", "Erfolgreich
    gesendet".
  - The same validation rules run in the browser and on the server, so they
    can't disagree. The browser bundle contains no zod; I checked the build
    output.
  - Error messages are translated. If the server rejects a field, the error
    shows on that field; a network or server failure shows one message above the
    button.
  - It also works with JavaScript off: errors appear after the page reloads, and
    after a successful send, reloading can't send it twice.
